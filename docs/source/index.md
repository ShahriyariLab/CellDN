# CellExLink documentation

CellExLink is a biomedical text-mining package for cell-type named entity recognition, Cell Ontology normalization, and end-to-end cell-type extraction from biomedical text. This documentation focuses on installation, model setup, usage, input and output formats, and common troubleshooting.
